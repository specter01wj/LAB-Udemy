Exercise 3: Student Grades

Requirement:

Create a Java program that determines a student's grade using the ternary operator.

Grading rules:
- 90 and above → Grade A
- 80 and above → Grade B
- 70 and above → Grade C
- 60 and above → Grade D
- Below 60 → Grade F

Functionality:

- Input: student score (int or double)
- Use ternary operator to determine grade
- Output the grade

Learning Objective:

- Practice ternary operator
- Understand conditional evaluation
- Replace if-else with compact syntax
