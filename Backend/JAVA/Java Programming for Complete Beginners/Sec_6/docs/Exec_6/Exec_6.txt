Exercise 6: Using Multiple Locks to Synchronize Threads with Bank Accounts

Requirement:

Create a multithreaded banking system using multiple locks.

Classes:

1. BankAccount
   Attributes:
   - accountNumber (int)
   - balance (double)

   Constructor:
   - initialize accountNumber and balance

2. BankTransactionDemo
   - Create a list of BankAccount objects

3. Runnable Tasks:
   - DepositTask
   - WithdrawTask

DepositTask:
- Lock specific account
- Deposit random amount (100–500)
- Unlock
- Repeat multiple times

WithdrawTask:
- Lock specific account
- Withdraw random amount (50–200) if sufficient balance
- Unlock
- Repeat multiple times

Main Flow:
- Create multiple accounts
- Start multiple threads (deposit + withdraw)
- Wait for all threads (join)
- Print final balances

Learning Objective:
- Practice multithreading
- Use multiple locks
- Avoid race conditions
